# Visual UI Design

## Why this matters

Visual design directs attention, creates hierarchy, and supports comprehension. It should clarify interaction and content rather than add decoration that competes with them.

## Core concepts

- **Visual hierarchy:** Use size, weight, contrast, position, and spacing to communicate priority.
- **Typography:** Establish readable scales, line lengths, weights, and styles with a clear purpose.
- **Layout and grids:** Use alignment and consistent spacing to make dense information scannable.
- **Color:** Communicate meaning deliberately; do not rely on color alone.
- **Gestalt principles:** Proximity, similarity, alignment, and enclosure help people perceive groups and relationships.

## Think through

1. What should a user notice first, second, and third?
2. Does spacing communicate groups and separation consistently?
3. Can a user scan data-heavy content without reading every word?
4. Is color semantic and accessible, or merely decorative?
5. Does the interface still work in grayscale or high-contrast settings?

## Practice

Take a dashboard or settings screen and redesign its hierarchy using only typography, spacing, alignment, and semantic color.

## Deliverable

Create a high-fidelity screen with annotations explaining hierarchy, grid, spacing, typography, and color decisions.

## Common interview questions

### How do you create visual hierarchy on a data-heavy screen?

I identify the user's primary decision and make the information needed for that decision easiest to scan. I use clear grouping, a predictable grid, meaningful headings, restrained typography, whitespace, and semantic color. I avoid making every number equally prominent; secondary detail should remain available without competing with the main task.

### How do you handle subjective feedback about visual design?

I ask what problem the feedback is trying to solve, then bring the conversation back to user goals, design principles, accessibility, consistency, and evidence. If multiple approaches are reasonable, I show them in context and test or compare them against agreed criteria. That keeps feedback constructive without dismissing stakeholder input.

## Key terms / cheat sheet

- **Visual hierarchy:** The order in which the interface draws attention.
- **Semantic color:** Color assigned a consistent meaning, such as success or error.
- **White space:** Intentional empty space that separates and groups content.

## Scenario challenge

Redesign a crowded operational dashboard so a manager can identify urgent exceptions in under 10 seconds without hiding supporting data.

## Common pitfalls

- Giving every element equal visual weight.
- Using color as the only signal for status or meaning.
- Mistaking a dense layout for an efficient layout.

## Review checklist

- [ ] The screen's primary decision is visually dominant.
- [ ] Typography, spacing, and alignment are consistent.
- [ ] Status and meaning do not depend on color alone.

## Portfolio evidence

Include hierarchy annotations, the design rationale, a before-and-after comparison, and accessibility considerations.

## Flashcards

**Q:** What is visual hierarchy?  
**A:** The intentional ordering of attention through contrast, position, size, and spacing.

**Q:** Why use semantic color?  
**A:** Consistent meaning helps users recognize status quickly and supports a scalable system.
